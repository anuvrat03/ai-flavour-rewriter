# ⚡ OpenRouter AI Document Transformer & Word Exporter

An interactive, serverless web tool built with standard HTML, CSS, and JavaScript. It transforms raw text or document excerpts into various structural styles (Academic, Educational Metaphors, Executive Summaries, and Storytelling) using free AI models via the **OpenRouter API**, and exports the result directly into an editable **Microsoft Word (.docx)** file.

---

## ✨ Features

- **Multi-Style Transformations:**
  - 🎓 **Academic & Research Paper:** Converts casual text into structured formal literature with academic terminology.
  - 💡 **Educational & Metaphors:** Breaks complex concepts down into relatable analogies and visual bullet points.
  - 📊 **Executive Summary:** Condenses articles into clean management memos with action items.
  - 📖 **Narrative & Storytelling:** Rewrites factual documents into engaging narrative prose.
  - 👶 **Simplified Reader:** Formats content for basic understanding.
- **Direct Word Export (.docx):** Client-side document generation allowing 1-tap exports to MS Word, Google Docs, or Samsung Notes.
- **Privacy-Focused:** API keys are stored only in your browser's `localStorage` and never transmitted to external databases.
- **Zero Hosting Costs:** Designed to run 100% on GitHub Pages or local web editors (like TrebEdit).

---

## 🚀 How to Use

1. Get a free API key from [OpenRouter.ai](https://openrouter.ai).
2. Open the web application.
3. Paste your OpenRouter API Key into the setting field.
4. Input or paste your source text/article.
5. Select your desired transformation flavor and tap **Transform Document**.
6. Click **Download Word (.docx)** to open the formatted document in Google Docs or your device's word processor.
